# RepoTales Frontend

React 19 + Vite + Tailwind frontend for the RepoTales saga engine.

See the [project README](../README.md) for the full documentation, Docker
quickstart, architecture, and API contract.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api → :8080
npm run build    # production bundle in dist/
npm run lint     # oxlint
```
